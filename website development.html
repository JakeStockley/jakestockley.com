I am very proud to say that this website is fully my creation. No website creator was used, nor was any AI used to generate code. This is all my work. All of these points are tackled below in bullet points, and operate around the form of "frequently asked questions"

  • Why didn't you use a website creator?
    Cost, skills and control. Website creators (good ones) cost a fair amount of money, and are often bundled with things I don't need like hosting and domain names. I also have the personal skill to write decent code myself, simply putting me into glorified Microsoft publisher for websites would be a waste. Also putting me into such as "plug and play" environment would have most likely decreased my creative freedom. I enjoy showcasing my skills and enjoy creating things.
  • What code do you use?
    HTML and CSS. That's it, not even any JavaScript
  • What software do you use?
    I use geany to code, git to handle version control and cloud storage and cloudflare to publish and host.
  • How much does it cost you to run?
    .com domains cost ~$10 per year to keep the rights too. Everything else is free. Bear in mind that free storage and hosting does have it's drawbacks. No files over 25MB, you don't get premium service and your website's data is almost certainly collected and sold by data brokers. As this website's code is publicly available and under a public-accessable licence, that is of no issue to me.
  • This looks cool, can I code something like this?
    Yes, and it's not that hard. You will have to put effort into learning HTML and CSS though. Feel free to experiment with this website, it's code is freely available on my github.
  • Did you use any AI?
    No, I have a very set AI-policy. Anything that I create that I care about is not made with AI, even if AI can do better than me. It is through mistakes, hard work and practice that we gain skills and proficiency in life, and to be able to point at something worth of praise and say "I made that!" is one of the best feelings you can have.
    However, I do use AI for the useful tool it is. While AI does not code my website, it is an amazing teacher. AI taught me alot about coding, and can point out mistakes in my work. AI is best used as an assistant, not a replacement.
